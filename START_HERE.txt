RETAIL AI SALES INTELLIGENCE — ALL FILES

Recommended version:
  Project/retail-ai-sales-intelligence-v2/

This is the latest integrated project and includes the dashboard, FastAPI service,
forecasting, RFM customer segmentation, inventory planning, pipeline, sample data,
and automated tests.

WINDOWS QUICK START (open a terminal in the project folder):
  py -3.11 -m venv .venv
  .\.venv\Scripts\Activate.ps1
  python -m pip install -r requirements.txt
  python -m pytest
  streamlit run app/Home.py

Open a SECOND terminal in the same project folder, activate .venv, then run:
  uvicorn api.main:app --reload

Dashboard: http://localhost:8501
API docs:  http://localhost:8000/docs

To run the batch pipeline:
  python -m src.retail_ai.pipeline --forecast-products 5 --forecast-horizon 30 --backtest-days 28 --clusters 4 --lead-time-days 7 --service-level 0.95

Older project versions are included in Previous_Versions for reference. Use the latest
integrated project above unless you specifically need an earlier version.
